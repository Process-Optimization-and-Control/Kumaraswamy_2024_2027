# Kumaraswamy_2024_2027
Phd - Archana Kumaraswamy

This repository contains the code, manuscripts, and supporting material developed during my PhD.

The projects primarily focus on modeling, optimization, and control of carbon dioxide transport and injection processes. This includes Nonlinear Model Predictive Control (NMPC) and PID Control Frameworks.

Each project directory typically contains the code used for simulations as well as the manuscripts. Certain projects use LedaFlow, a dynamic multiphase flow simulator, for simulations. These directories contain a LedaFlow file export (*.qz).  

This repository serves both as a record of the research conducted during the PhD and as a collection of reproducible computational studies associated with the published work.
