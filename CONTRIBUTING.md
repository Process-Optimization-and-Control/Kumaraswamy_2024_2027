# Contributing

Small, reviewable contributions are welcome. For research code, explain the
scientific motivation as well as the implementation.

1. Open an issue describing the question, assumption, or bug.
2. Create a focused branch from the default branch.
3. Make the smallest change that addresses the issue.
4. Add a test or reproducible example for changed behavior.
5. Run the relevant Julia tests locally.
6. Open a pull request and complete its checklist.

When using Copilot, treat generated code as a proposal. Verify equations,
units, edge cases, dependency changes, and numerical results before requesting
review.
