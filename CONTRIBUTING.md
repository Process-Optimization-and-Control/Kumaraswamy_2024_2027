# Contributing

1. **Open an issue** describing the change and why it is needed.
2. **Create a branch** from `main` (from the issue page: *Development → Create a branch*).
3. **Make a small, focused change**, and add a test if behaviour changes.
4. **Open a pull request** and fill in the checklist. Write `Closes #<issue>`
   to link the issue.
5. **Merge** once the automated checks are green and the change has been reviewed.

For research code, explain the assumptions and units behind a change, not
just the implementation.
